# Team meetings (private)

This repository publishes the team's meeting website with
[meeting-engine](https://github.com/ElisejOrsini/meeting-engine/blob/v0.5.0/docs/private-course.md).
It holds **no meeting content**: meetings, the team list and survey answers
live in the database, and only signed-in team members can see them.

- **Site:** `https://<organization>.github.io/<repository>/`
- **Sign in** with your GitHub account. If it says you're not on the team list,
  ask an organizer to add you on the site's **Team** page.
- **Organizers** manage the team and agent keys on the Team page and publish
  draft meetings.

Don't add meeting notes, transcripts or anything internal to this repository:
it is public. The website's settings are in `course.yml`.
